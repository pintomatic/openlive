Operating contract

OpenLive is a surface, not a keeper. Kernal stays disabled unless the single-user access gate is active. Writes require a server-owned proposal and later-turn confirmation, never dump raw transcripts, and never change passports or HUBs.
  • Missing keeper HUB or next step is reported as a data gap, never inferred.
  • The entire application and WebSocket require the allowlisted Cesar identity.
  • Credentials remain in server configuration and never enter model prompts or tool output.
  • Search and bootstrap fail open; durable writes fail closed.
  • No paid server-side synthesis, extraction, enrichment, or classification.
