# OpenLive natural voice benchmark

Date: 2026-07-17

AWS region: eu-west-1

Compute: AWS CodeBuild `BUILD_GENERAL1_SMALL` Linux GPU, NVIDIA A10G 23 GB

## Decision

Keep the iPhone native voice as OpenLive's production default.

Chatterbox Turbo is the viable open-source candidate for a second experiment, but its official Python API did not stream first audio. It generated complete utterances quickly, then returned the buffered waveform. That adds 1.4 to 3.3 seconds before playback and does not preserve OpenLive's current conversational feel.

CosyVoice 3 is rejected for this surface in its official baseline form. After removing optional training and TensorRT dependencies, the model downloaded successfully but produced no first audio during a bounded A10G warmup/inference interval.

## Chatterbox Turbo

| Metric | Result |
| --- | ---: |
| Model load | 38.66 s |
| Median complete-utterance generation | 2.33 s |
| P95 complete-utterance generation | 3.16 s |
| Median real-time factor | 0.360 |
| Peak GPU memory | 3,309 MB |
| Official streaming API measured | No |

Ten OpenLive-style utterances were generated. Audio duration ranged from 3.72 to 9.60 seconds, while complete-waveform generation ranged from 1.45 to 3.34 seconds. The model therefore ran about 2.8 times faster than real time, but playback could not begin until each waveform was complete.

The local listening samples are retained under the ignored `runs/fc8342d0/results/chatterbox-turbo/` directory.

## CosyVoice 3

The official repository required a Python 3.10 environment and a large dependency set. TensorRT and DeepSpeed were optional for this inference path but blocked a clean baseline installation and were filtered from the benchmark environment. The Fun-CosyVoice3-0.5B-2512 snapshot then downloaded successfully. The warmup streaming call did not yield audio before the benchmark deadline, so no defensible latency metrics were recorded.

## Cost and cleanup

Six ephemeral CodeBuild runs consumed 3,358.5 seconds, or 55.98 billed minutes. The official eu-west-1 GPU-small rate was USD 0.06 per minute, giving an estimated compute cost of USD 3.36 before tax. This exceeded the original USD 2.25 cap by USD 1.11 because dependency-debug runs accumulated before the successful Chatterbox measurement.

The CodeBuild project, S3 bucket, CloudWatch log group, IAM inline policy, and IAM role were deleted and their absence was verified. No EC2 instance, SageMaker endpoint, or persistent GPU service was created.

## Next experiment

Do not integrate either model into the live voice loop yet. If naturalness still warrants another trial, test a genuinely streaming Chatterbox runtime against a hard first-audio gate of 800 ms. Stop the experiment if that gate cannot be met while retaining the current native voice as fallback.
